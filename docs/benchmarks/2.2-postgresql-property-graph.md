# PostgreSQL 19 property-graph benchmark record

This record captures the Phase E local calibration performed on 2026-09-03.
It is an engineering regression baseline, not a production-capacity claim.

## Qualified environment

| Component | Value |
|---|---|
| Host | Apple M4 Max, macOS arm64 |
| Go | 1.27.0 darwin/arm64 |
| Container runtime | Apple Container 1.0.0 |
| PostgreSQL image | `postgres:19beta3@sha256:a48b19841e04b35b72a25e9a94314ac80546d32b5e2e3cd9279390cbd8a99572` |
| Linux manifest | `sha256:d2803db84af749f279166b231e05a92c7d5ef991540cb292a76fb41af997ebd4` |
| Server | PostgreSQL 19beta3, `server_version_num` 190000 |
| Target limit | 4 vCPU, 2 GiB container memory |

The measured operation is a complete CSV `create` migration. It includes
source decoding, bounded 10,000-row batches, durable metadata checkpoints,
relational and `GRAPH_TABLE` finalization checks, and full 256-range canonical
digest generation. Fixture generation and cleanup are outside the timed region.

## Results

| Profile | Vertices | Edges | Trials | Mean time | Throughput |
|---|---:|---:|---:|---:|---:|
| Small | 10,000 | 25,000 | 3 | 0.498 s | 71,350 rows/s |
| Medium | 100,000 | 250,000 | 3 | 4.361 s | 81,029 rows/s |

Go's allocation counter measured approximately 181 MB per small operation and
1.81 GB per medium operation cumulatively across all allocations. That counter
is allocation volume, not resident memory. Bounded-memory safety is established
by the batch-sized temporary endpoint join and functional recovery suite; this
local record does not claim a production RSS ceiling.

## Reproduction

Start the pinned target, resolve its DSN as described in the development
environment guide, and run:

```sh
AGEFREIGHTER_PGGRAPH_TEST_DSN='postgres://...' \
  make bench-pggraph PGGRAPH_BENCH_PROFILE=small \
  PGGRAPH_BENCH_TRIALS=3 \
  PGGRAPH_BENCH_OUTPUT=.local/pggraph-small.txt

AGEFREIGHTER_PGGRAPH_TEST_DSN='postgres://...' \
  make bench-pggraph PGGRAPH_BENCH_PROFILE=medium \
  PGGRAPH_BENCH_TRIALS=3 \
  PGGRAPH_BENCH_OUTPUT=.local/pggraph-medium.txt
```

The harness refuses to overwrite evidence. Its production profile is fixed at
160,000,000 vertices and 400,000,000 edges and requires the exact acknowledgement
`PGGRAPH_BENCHMARK_PRODUCTION_ACK=160000000-400000000` to prevent accidental
execution. It must be run only in a separately budgeted, monitored environment
with retained resource and correctness evidence.

PostgreSQL 19 Beta 3 is upstream pre-release software. Production-scale
execution and PostgreSQL 19 GA digest qualification remain explicit promotion
gates; until then, agefreighter makes no production support or throughput claim
for the native target.
